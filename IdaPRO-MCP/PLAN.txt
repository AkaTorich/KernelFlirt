│ Component 1: IDA Plugin (plugin/ida_mcp_plugin.py)                                                                   │
│                                                                                                                      │
│ HTTP JSON-RPC Server                                                                                                 │
│                                                                                                                      │
│ - Запускается в отдельном threading.Thread при загрузке плагина                                                      │
│ - Использует http.server.HTTPServer + BaseHTTPRequestHandler (без внешних зависимостей)                              │
│ - Слушает на 127.0.0.1:13370 (настраивается)                                                                         │
│ - JSON-RPC 2.0 протокол: {"jsonrpc":"2.0","method":"...","params":{...},"id":1}                                      │
│                                                                                                                      │
│ Thread Safety Wrapper                                                                                                │
│                                                                                                                      │
│ def execute_on_main_thread(func, *args, **kwargs):                                                                   │
│     """Маршалит вызов на главный поток IDA через execute_sync."""                                                    │
│     result = {}                                                                                                      │
│     def wrapper():                                                                                                   │
│         try:                                                                                                         │
│             result["value"] = func(*args, **kwargs)                                                                  │
│         except Exception as e:                                                                                       │
│             result["error"] = str(e)                                                                                 │
│         return 0                                                                                                     │
│     ida_kernwin.execute_sync(wrapper, ida_kernwin.MFF_WRITE)                                                         │
│     if "error" in result:                                                                                            │
│         raise RuntimeError(result["error"])                                                                          │
│     return result.get("value")                                                                                       │
│                                                                                                                      │
│ API Methods (зарегистрированные JSON-RPC методы)                                                                     │
│                                                                                                                      │
│ Каждая категория — набор методов. Плагин регистрирует все через декоратор @api_method("method_name").                │
│                                                                                                                      │

│ JSON-RPC Protocol                                                                                                    │
│                                                                                                                      │
│ Request: {"jsonrpc":"2.0","method":"get_functions","params":{"start":0,"limit":100},"id":1}                          │
│ Response: {"jsonrpc":"2.0","result":[...],"id":1}                                                                    │
│ Error: {"jsonrpc":"2.0","error":{"code":-32000,"message":"..."},"id":1}                                              │
│                                                                                                                      │
│ Address Handling                                                                                                     │
│                                                                                                                      │
│ - Все адреса принимаются и возвращаются как hex строки ("0x401000")                                                  │
│ - Внутри конвертируются через int(addr, 16) / hex(addr)                                                              │
│                                                                                                                      │
│ ---                                                                                                                  │
│ Error Handling                                                                                                       │
│                                                                                                                      │
│ - IDA Plugin: JSON-RPC error codes (-32600 invalid request, -32601 method not found, -32000 server error)            │
│ - MCP Server: перехватывает httpx ошибки, возвращает понятные сообщения ("IDA not connected", "Method failed")       │
│ - Timeout: 30s по умолчанию для обычных операций, 120s для decompile/analysis                                        │
