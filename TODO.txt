PE Rebuilder / Import Reconstructor — как Scylla. Автоматический фикс IAT, восстановление импортов для дампов. Часть логики уже есть в ThemidaPlugin, можно вынести в универсальный плагин.

Memory Scanner — поиск паттернов/сигнатур в памяти процесса (AOB scan). Как Cheat Engine но в отладчике.

Trace Logger — запись трейса выполнения (адрес, инструкция, регистры) в файл. Полезно для анализа обфускации и VM-based протекторов.

Signature Scanner — определение компилятора/протектора по сигнатурам (как PEiD/Detect It Easy). Частично есть в AnalyzeProtector, но можно расширить с базой сигнатур.

Bookmarks / Notes — сохранение заметок привязанных к адресам между сессиями. Аннотации прямо в дизассемблере.

Diff / Patch Manager — сравнение двух состояний памяти (до/после распаковки), генерация патчей.

String Decryptor — автоматическая расшифровка строк в малвари (трейсит функцию дешифровки и собирает результаты).
